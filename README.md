# superopt

A superoptimizer that looks for missed optimizations in LLVM. It harvests small integer
instruction sequences from real C programs compiled with `clang -O2`, searches for cheaper
equivalent sequences, and keeps only rewrites that pass three independent correctness checks
and that `opt -O2` still does not perform.

This README is a stub. Results, design, and reproduction steps are added as the pipeline is
built. Every number that appears here is generated by `superopt report`.

## Requirements

- Python 3.12 and [uv](https://docs.astral.sh/uv/)
- An LLVM and Clang build with assertions, plus Alive2's `alive-tv` (only for the toolchain
  test suite and the full pipeline; the fast test suite needs neither)

## Quick start

```
uv sync
make lint test
```
